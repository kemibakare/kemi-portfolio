# Oluwakemi Elizabeth Bakare - Student Portfolio (COS 106)

Pages: index.html, about.html, projects.html, planner.html, contact.html
Folders: css/ (style.css), js/ (script.js), assets/ (images, audio)

## Run on your laptop
Double-click index.html (opens in your browser). Or in VS Code: right-click index.html > Open with Live Server.

## Upload to GitHub
1. Create an account at github.com, click New repository, name it e.g. kemi-portfolio, keep Public, click Create.
2. Click "uploading an existing file", drag in EVERYTHING inside the portfolio folder (index.html, the other pages, css, js, assets folders), then Commit changes.
   (Make sure index.html is at the top level of the repository.)

## Host it free (GitHub Pages)
1. In the repository: Settings > Pages.
2. Source: Deploy from a branch > Branch: main, folder: / (root) > Save.
3. Wait 1-2 minutes. Your link will be https://YOUR-USERNAME.github.io/kemi-portfolio/
4. Submit that link plus the repository link.
Then replace the "#" in the Live Link buttons on projects.html with real links if you have them.
